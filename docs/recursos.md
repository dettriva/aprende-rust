<div class="chapter-meta">

Una colección organizada de los mejores recursos para aprender Rust, con énfasis especial en materiales útiles para desarrolladores que vienen de Python.

!!! tip "Top 5 para empezar"

    Si acabas de llegar a Rust y no sabes por dónde empezar, estos son los **cinco recursos imprescindibles**:

    1. :orange_book: **The Rust Programming Language** — El libro oficial, gratuito y completo
    2. :crab: **Rustlings** — Ejercicios prácticos para aprender haciendo
    3. :rocket: **Rust by Example** — Aprende con ejemplos de código ejecutables
    4. :mortar_board: **Comprehensive Rust (Google)** — Curso intensivo y bien estructurado
    5. :wrench: **Rust Playground** — Experimenta sin instalar nada

## :wrench: Herramientas esenciales

Las herramientas que usarás a diario trabajando con Rust.

| Herramienta | Comando / Uso | Descripción |
|-------------|---------------|-------------|
| **rustup** | `rustup update` | Instalador y gestor de versiones del toolchain de Rust |
| **cargo build** | `cargo build --release` | Compila el proyecto (debug o release) |
| **cargo test** | `cargo test` | Ejecuta tests unitarios, de integración y doctests |
| **cargo run** | `cargo run` | Compila y ejecuta el binario del proyecto |
| **cargo clippy** | `cargo clippy` | Linter avanzado con sugerencias idiomáticas |
| **cargo fmt** | `cargo fmt` | Formatea el código según el estilo estándar de Rust |
| **cargo doc** | `cargo doc --open` | Genera documentación HTML del proyecto y dependencias |
| **cargo bench** | `cargo bench` | Ejecuta benchmarks del proyecto |
| **rust-analyzer** | Extensión LSP | Servidor de lenguaje para IDEs: autocompletado, errores en tiempo real |
| **cargo-watch** | `cargo watch -x test` | Recompila automáticamente al guardar cambios |
| **cargo-edit** | `cargo add serde` | Añade, elimina y actualiza dependencias desde la terminal |
| **cargo-expand** | `cargo expand` | Muestra el código expandido tras aplicar macros |
| **sccache** | Caché de compilación | Acelera recompilaciones compartiendo caché entre proyectos |
| **miri** | `cargo +nightly miri test` | Detecta comportamiento indefinido en código unsafe |
| **criterion** | Crate de benchmarking | Framework de benchmarking estadístico preciso |

!!! info "Equivalencias con Python"

    | Python | Rust |
    |--------|------|
    | `pip install` | `cargo add` |
    | `python -m pytest` | `cargo test` |
    | `black` / `ruff format` | `cargo fmt` |
    | `ruff` / `flake8` / `pylint` | `cargo clippy` |
    | `python -m venv` | Cargo maneja esto automáticamente por proyecto |
    | `python script.py` | `cargo run` |

## :snake: De Python a Rust

Recursos especialmente relevantes para desarrolladores Python que están aprendiendo Rust.

| Recurso | Descripción | Nivel | Enlace |
|---------|-------------|-------|--------|
| **PyO3** | Bindings para escribir módulos nativos de Python en Rust | :yellow_circle: Intermedio | [pyo3.rs](https://pyo3.rs/) |
| **maturin** | Herramienta para compilar y publicar paquetes Python escritos en Rust | :yellow_circle: Intermedio | [maturin.rs](https://www.maturin.rs/) |
| **RustPython** | Intérprete de Python escrito en Rust | :red_circle: Avanzado | [rustpython.github.io](https://rustpython.github.io/) |
| **pydantic-core** | El motor de validación de Pydantic v2, escrito en Rust | :yellow_circle: Intermedio | [github.com/pydantic/pydantic-core](https://github.com/pydantic/pydantic-core) |
| **ruff** | Linter de Python ultrarrápido escrito en Rust | :green_circle: Principiante | [github.com/astral-sh/ruff](https://github.com/astral-sh/ruff) |
| **uv** | Gestor de paquetes Python escrito en Rust (reemplazo de pip) | :green_circle: Principiante | [github.com/astral-sh/uv](https://github.com/astral-sh/uv) |

!!! info "El puente Python-Rust"

    Muchas herramientas modernas del ecosistema Python (ruff, uv, pydantic-core, polars) están escritas en Rust. Aprender Rust te permite contribuir a estas herramientas y crear tus propias extensiones de alto rendimiento con **PyO3** y **maturin**.

    ```bash
    # Crear un módulo Python con Rust
    pip install maturin
    maturin init --bindings pyo3
    maturin develop
    ```

!!! example "Proyecto sugerido para pythonistas"

    Un excelente primer proyecto es reescribir una herramienta CLI que ya tengas en Python. Por ejemplo:

    - Un script que procese archivos CSV :arrow_right: usa `csv` + `clap`
    - Una API REST sencilla :arrow_right: usa `axum` + `serde` + `sqlx`
    - Un web scraper :arrow_right: usa `reqwest` + `scraper`
    - Un generador de reportes :arrow_right: usa `tera` (templates) + `chrono`
